# Image Editor Shortcuts

The editor uses Qt standard key sequences, which follow platform conventions.

| Action | Shortcut |
| --- | --- |
| Open image | `Ctrl+O` on Windows/Linux; `Cmd+O` on macOS |
| Save editable document | `Ctrl+S` on Windows/Linux; `Cmd+S` on macOS |
| Save editable document as | `Ctrl+Shift+S` on Windows/Linux; `Cmd+Shift+S` on macOS |
| Undo | `Ctrl+Z` on Windows/Linux; `Cmd+Z` on macOS |
| Redo | Qt standard Redo sequence (`Ctrl+Y` on Windows/Linux; `Cmd+Shift+Z` on macOS) |
| Cancel crop selection | `Esc` |

Use the mouse wheel to zoom, the middle mouse button to pan, and the Crop
Selection toolbar or Edit menu action to start a crop gesture. No custom
shortcuts are assigned to rotation, flipping, fit-to-window, export, or
opening `.cimg` documents.
