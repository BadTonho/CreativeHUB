# Legacy documentation

This directory keeps historical planning records that no longer belong in the
active application roadmaps. The archived checklists preserve completed
implementation work and its original milestone context. They are not current
feature specifications or release-acceptance records.

Use each application's scope and format documents for current behavior, its
active roadmap for remaining work and acceptance gates, and its regression
guide or coverage index for verification evidence.
