# Ideias para o produto

Estas são anotações exploratórias. Elas não são requisitos aprovados do produto.

**Status:** Anotações provisórias de planejamento, de uso interno do mantenedor; não definem escopo aprovado nem compromissos de lançamento.

- Adicionar uma central de ajuda para encontrar recursos no aplicativo.
- Considerar o atalho Shift+Tab para abrir uma janela pesquisável de recursos e atalhos.
- Melhorar a navegação entre quadros nos cortes para que a prévia mostre claramente o próximo quadro.
- Adicionar retenção configurável de backups, com três versões salvas por padrão, além dos salvamentos automáticos.
- Quando a primeira versão estiver pronta, criar um processo de changelog para facilitar a comunicação das melhorias de cada lançamento.
- Atualizar imediatamente as sobreposições de texto enquanto suas configurações estiverem sendo editadas.
- Explorar uma forma controlada de permitir que ferramentas de IA interajam com o editor.
- Oferecer modos de exibição do áudio na linha do tempo, mostrando o audio mono, ou esterio
- Avaliar a possibilidade de integrar o Prism Downloader.
- Investigar tecnologias de compressão para Linux que possam beneficiar o editor.
- Explorar o suporte a sistemas com várias GPUs.
- Adicionar um mecanismo de atualização baseado nos lançamentos do GitHub.
- Considerar uma ferramenta de reparo interna ou independente para diagnosticar os arquivos do aplicativo quando ele não conseguir iniciar.
- Adicionar um processo portátil para fazer backup e restaurar configurações após reinstalações, verificando a ausência de recursos como fontes.
- Explorar um hub de aplicativos para downloads e acesso a ferramentas externas de reparo.
- Adicionar recursos beta opcionais para que os usuários possam experimentar atualizações frequentes sem afetar a experiência estável.
- Permitir que os usuários atribuam atalhos a qualquer recurso compatível, inclusive aos que não têm um atalho padrão.
- Facilitar o compartilhamento de arquivos de projeto com outras pessoas.
- Avaliar opções de backend de renderização, incluindo DirectX, Vulkan, Metal e OpenGL.
- Otimizar camadas de vídeo sobrepostas para evitar decodificar ou compor pixels totalmente encobertos e, portanto, invisíveis.
