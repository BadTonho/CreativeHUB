# Asset Provenance

The four PNG application icons in `app-icons/` are original artwork drawn manually by the project maintainer. They were created for this project and do not incorporate third-party icon packs or copied proprietary artwork.

The Windows multi-resolution `.ico` files in the same directory are generated from those PNG sources by [`scripts/generate_windows_app_icons.ps1`](../../scripts/generate_windows_app_icons.ps1). Regenerate them after changing a PNG source so the executable icons stay in sync.

These assets are distributed with the project under the repository's license. No separate third-party asset license is required for the application icons.
