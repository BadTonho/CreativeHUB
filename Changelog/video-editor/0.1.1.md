# Video Editor 0.1.1

Status: **Unreleased**. Changes accumulated since the published 0.1.0 baseline.

## Gaussian Blur interchange

- Add Fusion-only Gaussian Blur in Effects/Favorites/Functions, static radius/Enabled Inspector, typed masking, shared CPU/GPU processing and editable cscomp v3 ordered effects. Persist the node in CSP v31.

## Editable shape masks

- Transfer editable Rectangle/Ellipse source, effect and Transform masks to Motion through `.cscomp` v2, preserving shared identity and composition-time curves. Reuse the shared coverage rasterizer and retain CSP v30.

## Composition interchange

- Add editable `.cscomp` composition import/export with Motion Studio, compatible Fusion conversion, source/layout preservation, CSP v30 persistence and worker-backed File commands.
- Refresh timeline, Inspector and preview after interchange insertion at the global playhead; commit prepared media without copying cached frames. Report incompatible outer clip processing as a normal export refusal.

## Added

- Add the complete pt-BR translation for the visible Video Editor interface,
  bundle it for offline use, and expose its catalog through the Hub translation
  manifest for delivery without replacing the application executable.

- Load the system-selected Qt translation catalog from shared per-user storage before creating the Video Editor interface. Portuguese regional locales select pt-BR; downloaded catalogs take precedence over bundled catalogs.

- Update Functions to share the workspace-aware Effects catalog, including generators and Fusion nodes/masks. Add/Enter/double click now create nodes in Fusion; Edit generators, Text and transitions are drag-only. Close only after accepted edits/drops, retain search without selection and keep normal history/dirty tracking.

- Replace Fusion Add Node controls with workspace-filtered Effects and Favorites. Add drag/double-click creation for generators, core nodes and masks, preserve cable insertion for visual filters, and hide incompatible tools without losing saved favorites. Keep Grid controls and CSP v29 unchanged.

- Add the opaque-white Background preset under Video > Generators, local draggable Favorites, and shared Edit/Fusion RGBA controls for Background nodes. Preserve independent composition names through editing, CSP v29 saves and recovery.


- Add Inspector-edited Rectangle/Ellipse Fusion masks with typed ports, geometry keyframes, coverage VIEW, split/trim/FPS continuity and CPU/GPU mask composition. Introduce CSP v28 mask data, retained in current v29 saves, recovery and Hub backups.


- Add independent Fusion Composition clips in Effects > Video, with generated
  duration, normal Inspector effects/transforms, duplication, transitions and
  history. Preserve input-video time through split/trim and project FPS changes.
- Add static Background RGBA and Text generators to Fusion graphs, including
  source-free transparent output, shared preview/export preparation and node
  Viewer routing. Existing Transform/Brightness animation remains available.
- Save CSP v27 with composition graphs and generator data; retain versions 1–26
  and integrate autosave/recovery and Hub backup restoration. Preserve cubic
  Bezier easing when saving clip and node curves in v27.

- Added Adjustment Clip in Effects > Video: generated video-track layers apply
  existing effects and keyframed transforms to the composition below them.
  Opacity controls adjustment strength; adjusted frames compose on CPU and
  ordinary frames retain their configured GPU path. Move, extend/trim, split,
  duplicate, delete, attribute clipboard and Undo/Redo are supported.
- Added `.csp` v26 adjustment persistence, autosave and recovery without media
  references. Versions 1–25 remain readable; older readers reject v26. Fusion
  on adjustments remains outside this version.

- Expanded the experimental GPU video pipeline with opt-in hardware decoding
  for preview and export, GPU processing for supported effects and Fusion
  graphs, and a native Windows D3D11/OpenGL/NVENC path on supported NVIDIA
  systems. GPU options remain disabled by default; broader hardware and
  platform validation is still pending.
- Added a Timeline track-header context menu for adding, renaming, reordering,
  and removing tracks.
- Added a Media Pool title-bar toggle that expands the Bins and Media docks to
  the full workspace height while keeping Preview and Inspector at their
  existing positions and sizes. The Timeline moves to the remaining area to
  the right of Media Pool. The Media Pool remains resizable and retains its
  latest width across normal and expanded layouts, repeated toggles, and editor
  restarts. Older saved width snapshots no longer override a newer adjustment.
  The toggle restores the previous dock arrangement. Dock title bars support
  reusable action buttons.
- Added an independent Inspector title-bar toggle for full-height expansion.
  Inspector-only expansion keeps Bins and Media in their normal geometry, while
  reapplying that geometry after the dock layout settles; Media Pool-only
  expansion affects only its own docks. The two modes can be combined in either
  toggle order. Toggling preserves Preview geometry, while
  dragging the Inspector divider can resize Preview naturally as the central
  area changes. The Timeline remains below Preview between Media Pool and
  Inspector. The Inspector keeps its latest width through normal and expanded
  resizing, toggles, and editor restarts; collapsing either dock preserves the
  other dock's expansion state.

## Improved

- Present Functions entries as spaced, rounded cards with scalable leading icons, clear hover/keyboard selection, muted unavailable items and full-name tooltips. Increase the resizable initial height for the taller rows while preserving search, drag and activation behavior.

- Refined Timeline dock resizing and workspace visibility, repositioned the
  monitor volume controls, and simplified Timeline zoom controls by removing
  the separate zoom-in and zoom-out buttons.
- Added per-export timing diagnostics for video decoding and Fusion graph
  evaluation.
- Windows setup executables and installer wizards now display the Video
  Editor's application icon.
- Project saves retain Motion publication positions through the v25 fields
  carried forward into `.csp` v26, avoiding linked-render restarts after clip
  edits. Supported older projects remain readable.

## Fixed

- Prevent cached Timeline indexes from restoring a cleared clip selection, keeping Fusion catalog creation disabled after deselection.


- Prevent swscale from writing beyond decoded RGBA storage by padding conversion
  rows and compacting them in place, retaining the existing public frame layout.

- Offer valid autosave recovery when the main project is missing or corrupt,
  even when its timestamp is newer than the recovery snapshot.
- Keep recovered snapshots through session close and failed saves. Remove them
  only after a successful save or explicit discard.
- Preserve complete decoded audio across small output blocks, resampling,
  cancellation, and the final decoder/resampler drain.
- Align WAV/AAC seek output with the actual PCM content, including codec
  priming and sample-rate conversion, so seeking does not introduce incorrect
  audio positions or content.
- Export shared Image Editor publications and clip-specific variants
  consistently with preview, including Fusion inputs and missing-publication
  fallback.
- Export linked Motion Studio visuals while retaining the original trimmed
  audio and mapping differing publication, Timeline, and export frame rates.
- Preserve linked Motion publication positions across split, trim, frame-rate
  conversion, Undo/Redo, and save/reopen.
- Respect source YUV color matrices and full/limited range in CPU decoding
  and native GPU conversion, correcting color mismatches in preview and export.
- Apply video display rotation and reflection to metadata, thumbnails,
  playback, and export; preserve oriented frames across seeking and reset.
- Allow silent video export when audio-only clips are offline and audio export
  is disabled, while retaining the complete Timeline duration and black tail.

## Maintenance

- Correct the Fusion workspace Debug regression to check that removing its last
  Brightness keyframe removes the curve entry, without accessing an empty vector.

- Use the revised shared update runtime with independent pending-app monitoring,
  schema-1 recovery, and per-app launch failure isolation. Add regressions for
  self-update shutdown and installer launch contention.

- Add Video Editor producer/consumer coverage for Hub backup relocation across
  project versions 1–25, including Fusion inputs, Image/Motion sidecars, and
  Motion publication positions.

- Keep the audio playback, system memory, and performance usage test checks
  active in Release builds instead of removing them through `NDEBUG`. Required
  audio initialization, decoding, and sampling operations are evaluated before
  their results are checked.
- Add a shared regression probe for condition evaluation and deliberate failure
  detection, with file, line, and condition diagnostics.
- Declare the Qt Gui dependency for the standalone preview-performance-metrics
  test, fixing its fresh-build failure at the composition boundary.
- Add permanent regression coverage for the ten reproduced audit defects,
  including recovery durability, PCM content, linked publications, tagged YUV
  color conversion, orientation, and silent export with offline audio.
