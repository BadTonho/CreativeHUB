# Video Editor 0.1.1

Status: **Unreleased**. Changes accumulated since the published 0.1.0 baseline.

## Color workspace

- Add a Color page with a shared viewer, clip strip, Primary Grade controls and
  an RGB waveform. Color and Edit share correction data, Timeline history and
  project dirty state.
- Add brightness, contrast, saturation and per-channel gain processing to
  Preview and export, with CSP v32 persistence and Hub backup compatibility.
  Add Alt+5 navigation and a dedicated roadmap for advanced color tools.
- Add a project-owned Color Gallery for full-canvas still capture, editable
  names, clip/frame provenance, and removal. Store lossless PNGs in a
  `<project>.csp.gallery/` sidecar with CSP v33 metadata; preserve them through
  Save As, autosave, recovery, and Hub backup/restore. Queue GPU readback on the
  playback worker and retain missing images as unavailable Gallery items.
- Replace the Color correction list with a functional node graph containing
  Input, effect, Parallel Mixer, and Output nodes. Connections drive rendering;
  parallel branches use normalized weighted RGBA mixing. Edit can change shared
  effect parameters and enabled state, while graph structure and layout are
  edited in Color. Removing a mixer keeps its first input as the output path.
  Preview, export, project history, and CSP v34 persistence use
  the graph; older effect stacks migrate to serial graphs. Add graph, migration,
  rendering, history, recovery, and Hub sidecar regression coverage. Fusion is
  unchanged.
- Temporarily hide the Color graph action buttons and effect-type selector while
  retaining their existing connections for later relocation.
- Expand Primary Grade with interactive Lift, Gamma, Gain and Offset RGB wheels,
  editable channel values, Contrast, Pivot, Temperature and Tint. Route every
  control through the shared CPU/OpenGL/Vulkan correction and preserve the
  previous output when the added controls are neutral. Color and Edit continue
  to edit the same project-owned parameters; wheel drags create one history edit.
- Add RGB Waveform and RGB Parade scopes from the corrected composed frame with
  a labeled 0–100% scale. Sample CPU RGBA directly and use a single bounded,
  asynchronous GPU readback on the playback worker; discard stale frame/project
  results without capturing the Preview widget.
- Advance CSP to v35. Migrate legacy Primary Grade brightness to equal RGB
  Offsets while preserving Contrast, Saturation, Gain, enabled state and graph
  topology. Keep the v33 Gallery PNG sidecar through Save As, autosave, recovery
  and backup/restoration. Add math, GPU, interaction, scope, migration and Hub
  boundary regression coverage; leave Fusion source and rendering behavior
  unchanged.

## Audio workspace

- Add an Audio page with an audio-only editable Timeline, shared playback and
  edit history, per-track gain/mute mixer, and live track/output peak meters.
  The project format and application version remain unchanged.
- Add the Audio workspace roadmap, navigation shortcut and regression checks
  for workspace switching, mixer Undo and pre-clipping level calculation.
- Translate the new Audio workspace controls and messages in the bundled pt-BR
  catalog.

## GPU Adjustment Clip stages

- Add an optional shared GPU operation for Adjustment Clips on OpenGL and Vulkan.
  Keep ordered color filters, transform sampling, opaque black exposed areas and
  clip-opacity mixing on textures between timeline stages. Preview retains direct
  texture delivery; export feeds the result into its existing RGBA/native paths.
- Keep CPU composition as the default and reconstruct unsupported or failed GPU
  frames through the existing CPU route without changing project formats or
  adding Fusion support inside Adjustment Clips.
- Add CPU/GPU parity coverage for both backends, preview texture delivery,
  transitions, upper layers, export, cancellation, rotation capability and
  bounded GPU resource pressure.

## Render workspace layout

- Extend only Render Settings into a resizable 480 px left dock from the top
  of the workspace to the application footer. Keep Preview and Queue in their
  existing central columns and the read-only Timeline in the lower dock beneath
  them; restore the previous dock arrangement when leaving Render. Defer the
  central page handoff until Qt finishes restoring the native dock layout, and
  update the Timeline control row after that layout settles.
- Clear Fusion node-canvas callbacks during workspace teardown so delayed scene
  notifications cannot access UI panels that are closing.

## Fusion node wire feedback

- Keep connected wires and their hit targets attached to node ports while either
  endpoint moves. Keep new-connection and rewire previews aligned with the
  pointer, and verify canceled drops leave the graph unchanged.

## Fusion grid snapping and wire styles

- Add a canvas context menu for globally persisted straight/curved wire styles
  and grid snapping. Snap moved and inserted nodes to the configured grid
  spacing; route snapped wires around other nodes and show the chosen route
  during connection and rewire drags.

## Panel layout gallery

- Add a gallery of Default, Preview Focus, and Timeline Focus arrangements,
  available from the top toolbar and View menu in Edit and Fusion. Save named
  panel layouts with schematic thumbnails, and apply, update, rename, or delete
  them across projects. Preserve dock visibility, tabs, floating panels, and
  expansion settings while retaining automatic restoration of the last layout.

## Inspector numeric controls

- Hide increment and decrement arrow buttons from numeric fields in the Edit
  and Fusion Inspectors while preserving direct entry, sliders, and keyframe
  controls. Decimal fields show three fractional digits. Press Up or Down in a
  focused field to use its configured step, Shift+Up/Down for 0.001, or
  Alt+Up/Down for 0.100, or Ctrl+Up/Down for 1.000. Modifier combinations use
  the configured step. Edit Transform arrow adjustments update the matching
  slider and preview immediately; each press and auto-repeat sequence is one
  Undo/Redo edit. Double-click a property name to reset its numeric control to
  the model default; Edit updates the Transform preview and slider immediately,
  while Fusion applies only that property and preserves other pending values.
- Replace Inspector keyframe glyphs with a shared vector diamond icon, outlined
  when the current frame has no key and filled gold when it does.

## Edit Preview layout

- Center the Edit Preview canvas using the active project's frame aspect ratio.
  Drag Preview to the outermost left or right workspace edge to let that side
  area extend to the footer while Timeline stays visible beside it. Docking
  Preview between other panels keeps its normal height, even in a side area.
  Persist the selected outer-edge layout and restore its lower-corner ownership
  on restart. Start the active Media Pool or Effects group at up to 25% of the
  useful window width, then allow free resizing with native dock dividers and
  persist those side-layout widths across restarts. Preserve the pre-docking
  panel widths separately and restore them when Preview is moved inside,
  floated, or closed.
  Allow the canvas to scale below its former 320×180 minimum when needed to
  preserve portrait proportions in a constrained dock. Fusion keeps its
  full-width Viewer and Render continues to use the shared Preview in its
  existing layout.

## Fusion output safety

- Reject graph evaluations that contain neither an RGBA frame nor a GPU texture
  in playback and offline export. Keep CPU compositor bounds safe for extreme
  finite and non-finite layer positions.

## Shared mask and update compatibility

- Use Rec.709 luminance for colored masks in CPU and OpenGL composition, with
  matching integer rounding. Resolve update installers from the canonical
  CreativeHUB release channel and consume Motion handoff through its CMake
  target.

## Media import and project validation

- Ensure an unexpected worker exception still completes the media import batch
  and clears its progress gate. Reject out-of-range audio envelope frames before
  integer conversion and provide safe behavior for an empty audio session.
- Retire failed GPU compositor instances and fall back to CPU when native GPU
  adapter creation is unavailable. Keep updater widgets in the Video Editor.

## Image Editor Hue/Saturation handoff regression

- Extend the real linked-image producer/consumer gate to Image v23 exposure plus
  HSL hue rotation, verifying expected PNG colors, mask alpha and isolated clip
  variants. Shared effect checks preserve existing Rec.709 saturation behavior.

## Image Editor exposure handoff regression

- Exercise refresh from an actual Image v22 producer with linear exposure,
  resized canvas and raster mask; retain transformed PNG colors and transparency.
  Shared compositor/effects consumer checks preserve existing Video behavior.

## Brightness/Contrast adjustment compatibility

- Reuse the shared RGB adjustment evaluator and extend typed Image raster adjustments without changing Video effects, registrations or linked PNG contracts. Native visual/platform acceptance remains pending.

## Shared Gradient Map raster maintenance

- Maintain opaque video output, native formats and linked PNG refresh while shared effects expose RGB Gradient Map math and OpenGL raster records gain optional alpha-preserving adjustments for Image. No Video effect selector or format change is introduced.

## Shared transparent blend composition maintenance

- Reuse shared channel/alpha helpers for CPU blending while retaining existing
  Normal fast paths, opaque video output and native formats. Preserve PNG image
  refresh compatibility with Image v19; consumer regressions cover the boundary.
- Maintain compatibility with additive OpenGL raster blend fields and budgeted
  backdrop handling. No Video blend selector or format change is introduced.

## Shared Drop Shadow processing maintenance

- Maintain compatibility with shared CPU effect and GPU image-operation extensions used by Motion Drop Shadow, including explicit Vulkan refusal and OpenGL resource/parity regressions. Video controls and document formats are unchanged.

## Shared logical mask raster maintenance

- Retain existing mask pixels, UI and persisted formats while shared coverage adds an optional logical receiver/raster window used by Motion Bezier shapes. Protect default behavior with existing composition/exchange/render consumer regressions.

## Shared Track Matte compositor maintenance

- Preserve Video's existing Normal/image-operation behavior while shared CPU and
  OpenGL gain an additive matte image operation for Motion; Vulkan refuses it
  explicitly. Keep Video UI and formats unchanged with consumer regression gates.

## Shared blend-mode compositor maintenance

- Preserve Video's Normal rendering and formats while shared CPU/OpenGL gain
  static layer blending for Motion and Vulkan explicitly requests fallback.
  Consumer composition/preview/export regressions protect the additive boundary;
  no Video blend-mode UI or persistence is added. Native GPU/platform acceptance
  remains separate from fallback coverage.

## Shared affine compositor maintenance

- Keep Video rendering contracts unchanged while shared CPU/precise OpenGL compositors gain an optional source-pixel affine override for Motion; Vulkan explicitly requests fallback for that contract. Existing uniform geometry remains the default. Consumer rendering/interchange regressions protect this additive boundary; native/platform acceptance remains separate.

## Reduced native pipeline intermediates

- Add private sampled BGRA input and direct integer-to-normalized output kernels,
  retaining legacy input conversion and existing public entry points.
- Schedule ordered prototype effects before canvas allocation and release temporary
  leases at last use, preserving GPU completion and synchronization contracts.
- Add disjoint known-memory diagnostics and native 4K codec/pixel/lifetime regressions
  within the existing 256 MiB session cap; keep decoder accounting separate and
  native editor input deferred. Preserve historical performance/refusal evidence.
- Prove H.264/HEVC input/output at 4K on the reference Windows device, with zero
  full video CPU downloads in measured native runs, and retain both complete
  benchmark protocols including their unexplained initial slow pair.
- Guard known allocation accounting against host metadata failures and cover exact
  rollback for images, transfers and both native bridges without invalidating the device.

## Native decoded-input research

- Extend the optional standalone Vulkan/NVENC probe with explicit D3D11VA NV12
  input tickets, shared BGRA conversion, bounded external-memory import and
  independent native/RGBA input/output diagnostics.
- Reuse the existing OpenGL fixed-point NV12 converter; preserve application
  input selection, formats, versions and native output eligibility.
- Cover tagged color, FIFO/resource pressure, reset/lifetime, injected faults,
  cancellation and end-to-end codec/pixel/timestamp checks. Record zero full
  video input/output CPU transfers in accepted cases and 4K capacity refusal
  without increasing the 256 MiB Vulkan/bridge/output limit.

## Qualified Vulkan native NVENC export

- Integrate the existing Vulkan/D3D11 bridge with the current export FIFO for
  qualified Windows H.264/HEVC NVENC preset tuples, without new interface controls.
- Share session-device reservations with preview/Fusion and bounded native encoder
  and RGBA recovery surfaces within the 256 MiB known allocation budget.
- Preserve codec selection, audio, timestamps, cancellation and atomic publication;
  retire pending native tickets and rebuild only unencoded frames after failure.
  Abort and retain bounded resources until process exit if retirement is unconfirmed.
- Add native qualification, resource-pressure, fault, Fusion parity and concurrent
  Viewer regressions and per-path diagnostics. Keep unqualified settings on RGBA,
  Vulkan experimental and Automatic on OpenGL; decoder-surface import is deferred.

## Separate Vulkan / NVENC prototype

- Add an optional standalone Windows Vulkan/D3D11/NVENC research executable,
  using the existing FFmpeg encoder and native pool as an independent diagnostic.
- Add opt-in adapter-LUID selection and a private keyed-mutex/external-memory
  bridge with FIFO tickets, bounded reservations, cancellation and safe retirement.
- Verify native BGRA delivery without full output CPU readback, retaining explicit
  GPU blit/copy accounting, codec selection and atomic destination preservation.
- Record native H.264/HEVC checks and three-trial RGBA/native performance evidence;
  keep Vulkan experimental and other platforms pending. This prototype initially
  left editor export unchanged; the integration above adds qualified native output.

## Vulkan preview pacing

- Track queued presentation and GPU command completion per frame, independently
  of later device work; preserve OpenGL diagnostic stages and append Vulkan stages.
- Limit each Viewer to one tracked presentation and its latest unsent frame,
  avoiding unchanged redraws and retiring stale generations without early reuse.
- Release empty reservations when nonblocking swapchain acquisition is unavailable.
  Preserve FIFO, transition snapshots, grayscale, the 256 MiB cap and export FIFO.
- Add native concurrent-Viewer/export regressions and a corrected per-frame latency
  comparison; keep Vulkan experimental and Automatic on OpenGL.

## Asynchronous Vulkan processing

- Batch Vulkan uploads, effects and Fusion commands using reusable completion
  contexts and bounded image/transfer pools, retaining the 256 MiB device cap.
- Defer unavailable preview images and remove normal per-frame queue-idle waits.
- Pipeline up to two ordered RGBA export readbacks, reducing parallelism under
  resource pressure and rebuilding unencoded frames on CPU after technical failure.
  Preserve codec selection, audio, cancellation and atomic output publication.
- Add asynchronous resource/queue diagnostics and a serial comparison environment
  setting; keep Vulkan experimental and Automatic on the existing OpenGL policy.

## Selectable graphics renderers

- Add an experimental Vulkan compositor for timeline preview, Fusion operations
  and RGBA export alongside the existing OpenGL and CPU paths.
- Add a translated startup renderer chooser, remembered preferences, next-launch
  settings, one-run command-line overrides, effective-backend diagnostics and
  recovery when Vulkan is unavailable. Retain separate GPU composition and codec
  controls and capture the selected backend in queued jobs.
- Wait briefly for released native OpenGL export targets before recovering through
  RGBA, preserving cancellation and the existing bounded resource pools.
- Prefer cached coherent Vulkan readback memory when available, while retaining
  coherent-memory fallback and the existing bounded allocations.
- Compile SPIR-V shaders at build time with optional Vulkan/glslang dependencies.
  Preserve the OpenGL consumers and dynamically load the Vulkan runtime.

## Gaussian Blur interchange

- Add Fusion-only Gaussian Blur in Effects/Favorites/Functions, static radius/Enabled Inspector, typed masking, shared CPU/GPU processing and editable cscomp v3 ordered effects. Persist the node in CSP v31.

## Editable shape masks

- Transfer editable Rectangle/Ellipse source, effect and Transform masks to Motion through `.cscomp` v2, preserving shared identity and composition-time curves. Reuse the shared coverage rasterizer and retain CSP v30.

## Composition interchange

- Add editable `.cscomp` composition import/export with Motion Studio, compatible Fusion conversion, source/layout preservation, CSP v30 persistence and worker-backed File commands.
- Refresh timeline, Inspector and preview after interchange insertion at the global playhead; commit prepared media without copying cached frames. Report incompatible outer clip processing as a normal export refusal.
