# Video Editor 0.1.1

Status: **Unreleased**. Changes accumulated since the published 0.1.0 baseline.

## Added

- Expanded the experimental GPU video pipeline with opt-in hardware decoding
  for preview and export, GPU processing for supported effects and Fusion
  graphs, and a native Windows D3D11/OpenGL/NVENC path on supported NVIDIA
  systems. GPU options remain disabled by default; broader hardware and
  platform validation is still pending.
- Added a Timeline track-header context menu for adding, renaming, reordering,
  and removing tracks.
- Added a Media Pool title-bar toggle that expands the Bins and Media docks to
  the full workspace height while keeping Preview, Inspector, and Timeline
  visible. The toggle restores the previous dock arrangement and persists its
  state across restarts. Dock title bars now support reusable action buttons.

## Improved

- Refined Timeline dock resizing and workspace visibility, repositioned the
  monitor volume controls, and simplified Timeline zoom controls by removing
  the separate zoom-in and zoom-out buttons.
- Added per-export timing diagnostics for video decoding and Fusion graph
  evaluation.
- Windows setup executables and installer wizards now display the Video
  Editor's application icon.

## Maintenance

- Use the revised shared update runtime with independent pending-app monitoring,
  schema-1 recovery, and per-app launch failure isolation. Add regressions for
  self-update shutdown and installer launch contention.

- Add Video Editor producer/consumer coverage for Hub backup relocation across
  project versions 1–24, including Fusion inputs and Image/Motion sidecars.

- Keep the audio playback, system memory, and performance usage test checks
  active in Release builds instead of removing them through `NDEBUG`. Required
  audio initialization, decoding, and sampling operations are evaluated before
  their results are checked.
- Add a shared regression probe for condition evaluation and deliberate failure
  detection, with file, line, and condition diagnostics.

## Validation

- On 2026-10-10, the 16 CTest entries affected by the test-check correction and
  the complete 103-test suite passed on Windows/Release. The deliberate failed
  check exited with code 1. Debug and macOS/Linux execution of that correction
  remain pending.
- Native GPU and packaged-runtime acceptance remain subject to the
  [regression guide](../../docs/video-editor/REGRESSION_TESTING.md) and
  [GPU pipeline contract](../../docs/video-editor/GPU_PIPELINE.md).
- The Media Pool dock-layout, Timeline dock-resize, and workspace page-switch
  UI regression tests passed on Windows/Release. Manual visual checks at wide
  and smaller window sizes, including native dock drag and float controls,
  remain pending.
