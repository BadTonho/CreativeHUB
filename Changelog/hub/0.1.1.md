# Creative Suite Hub 0.1.1

Status: **Unreleased**. Changes accumulated since the published 0.1.0 baseline.

## Fixed

- Preserve relative media and linked-document references when Image, Video,
  and Motion projects are copied into the backup vault or relocated for
  restoration. Snapshots retain their document version and editing data;
  original projects and media remain unchanged. Media are referenced, not
  bundled, and older snapshots require their original directory context.
- Reject unsupported document versions and invalid reference structures with
  a logged cause, without publishing an incomplete snapshot.

## Improved

- Windows setup executables and installer wizards now display the Hub's
  application icon.

## Maintenance

- Add producer/consumer backup regressions for all 46 currently supported
  document versions using the three editors' actual persistence code.

- Keep all ten Hub regression tests and the shared updater catalog test active
  in Release builds. Checks and required file setup are no longer removed by
  `NDEBUG`.
- Add a shared regression probe that verifies conditions are evaluated exactly
  once and that a deliberate failed check exits with a diagnostic identifying
  the file, line, and condition.

## Validation

- On 2026-10-10, all 14 backup-related CTest entries passed on Windows/Release,
  including all Hub tests and the three editor persistence consumers. The Hub
  and all three editor applications built successfully. Native restoration
  checks, Debug, and macOS/Linux execution remain pending.

- On 2026-10-10, the 16 affected CTest entries and the complete 103-test suite
  passed on Windows/Release. The deliberate failure exited with code 1.
  Debug and macOS/Linux execution of the new checks remain pending.
- See the [Hub regression guide](../../docs/hub/REGRESSION_TESTING.md) for
  coverage and pending installer/update acceptance.
