# Motion Studio 0.1.1

Status: **Unreleased**. Changes accumulated since the published 0.1.0 baseline.

## Layer Track Mattes

- Add Alpha/Alpha Inverted/Luma/Luma Inverted with Inspector source/mode selection,
  atomic source hiding and Undo/Redo, shared sources and cycle-checked chains.
  Evaluate isolated source pixels after existing effects, masks and affine
  geometry, before final blending; reuse immutable gesture scenes and caches.
- Persist bindings in native v14/recovery v1, preserve older projects without
  mattes and refuse nonrepresentable `.cscomp` v3 exports. Add CPU/OpenGL image
  operations and explicit Vulkan fallback, Hub backup coverage and EN/pt-BR UI.
  Visual/platform/native presentation acceptance and benchmarks remain pending.

## Static layer blend modes

- Add Normal, Multiply, Screen, Overlay, Add and Difference in the Inspector with
  static per-layer history, transparent backdrop semantics and opaque output.
  Reuse source/effect/mask caches and immutable preview/export snapshots; preserve
  Normal-only pixels and cancellation of transient Viewer edits.
- Persist optional modes in native v13/recovery v1, migrate older documents to
  Normal and explicitly refuse non-Normal `.cscomp` v3 exports by layer name/ID.
  CPU/OpenGL implement the shared contract; Vulkan requests existing fallback.
  Add EN/pt-BR labels and regression/manual check documentation. Visual/platform/
  native GPU acceptance and benchmarks remain pending.

## Viewer Scale X/Y drag

- Add X/Y/XY handles near the real pivot with live content/percentage preview,
  affine-aware linked/free scaling and positive limits that keep the gesture
  active. Commit static bases/animated keys, including between keys, only on
  release in one Undo/Redo; preserve other properties, cancellation/Redo and
  document/autosave isolation. Materialize implicit Y without resampling, counting
  copied and inserted keys toward the existing document limit.
- Reuse immutable scenes, bounded gesture scheduling, unique Position/Rotation/
  Scale sessions, source caches and existing effects/masks/rendering. Retain
  native v12, recovery v1, `.cscomp` v3, application versions and shared compositor
  contracts. Add EN/pt-BR instructions and automated geometry, controls, limits,
  history, rendering/export, persistence and session coverage at scales 1/2.
  Manual/platform/native GPU acceptance and benchmarks remain pending; keep the
  known OpenGL presentation failure separately recorded.

## Viewer Rotation drag

- Add a separate curved-arrow handle around the real pivot, with live local
  Rotation/content preview, positive/negative full turns, affine parent/binding
  angle mapping and a neutral center zone. Commit a static base or animated key,
  including between keys, only on release in one Undo/Redo. Preserve other
  authored transforms/curves, descendant inheritance, cancellation/Redo and
  autosave isolation. Retain subsequent Inspector edits that cancel the draft.
- Reuse immutable preview scenes, bounded gesture scheduling and caches with
  unique Position/Rotation session identities and recovery/paint validation.
  Retain native v12, recovery v1, `.cscomp` v3, application versions and shared
  compositor contracts. Add EN/pt-BR instructions and automated geometry,
  pointer/history/render/export/persistence/session coverage at scales 1/2.
  Manual/platform/native GPU acceptance and benchmarks remain pending; retain
  the known OpenGL presentation failure separately.

## Viewer Position drag

- Add a four-way movement handle beside the pivot, with live content and local
  Position X/Y preview, fractional pointer precision and capture outside the
  Viewer. Preserve affine parenting, Anchor, independent scales and descendant
  movement. Commit static bases/animated keys together on release, including
  insertion between keys, in one Undo/Redo; cancellation preserves Redo.
- Share immutable preview scenes and bound gesture scheduling to one running
  job plus the latest pending request. Reject obsolete session results, reuse
  source caches and retain masks/effects and GPU fallback behavior. Keep drafts
  outside document/autosave/recovery. Retain native v12, recovery v1, `.cscomp`
  v3, application versions and shared compositor contracts. Add EN/pt-BR text
  and automated geometry, gesture, queue, rendering and persistence coverage at
  display scales 1/2. Manual/platform/native GPU acceptance and benchmarks remain
  pending; the known OpenGL presentation failure remains separately recorded.

## Timeline Parent & Link pick-whip

- Add a row-header icon and current-parent label, full identity tooltips and
  drag-to-parent feedback, including duplicate names and invalid destinations.
  Support wheel/edge autoscroll and Null/hidden/offline/inactive layers while
  preserving clip alignment, row reordering and other timeline controls.
- Keep document/history/autosave unchanged during capture; commit through the
  Inspector's existing affine-compensated parent command once on release.
  Pause playback and cancel on Escape/Undo/context changes without discarding
  Redo. Share linear candidate preparation with the Inspector. Retain native
  v12, recovery v1, `.cscomp` v3 and all application versions. Add EN/pt-BR text
  and automated gesture/history/geometry/persistence coverage at scale factors
  1 and 2. Manual visual/platform acceptance and benchmarks remain pending;
  the previously recorded native OpenGL presentation failure remains separate.

## Viewer Pan Behind

- Drag the selected layer's pivot while preserving current-frame layer and
  descendant geometry, including Nulls and inherited affine shear. Preview local
  Anchor/Position values live without changing the document, creating keys or
  requesting new frames; commit once on release. Pause playback, retain the grab
  offset, and cancel with Escape/Undo or context changes without adding history.
  Reuse native v12/recovery v1 and existing compositor contracts. Add EN/pt-BR
  instructions and automated gesture, geometry, cache, persistence and history
  coverage. Manual visual/platform/GPU acceptance and benchmarks remain pending.

## Independent animated scale axes

- Add Scale X/Y percentage controls, proportional per-layer linking, independent timeline/Graph Editor curves and a uniform audio bake. Preserve full inherited shear through six-coefficient matrices, parenting/deletion and compensated Anchor edits. Retain the exact uniform legacy route and reuse caches; add CPU/precise OpenGL affine composition and Transform masks, with explicit Vulkan fallback. Write `.motion` v12, read v1–v11 defaults, retain recovery v1 and explicitly reject incompatible `.cscomp` scales/bindings. Automated geometry/UI/render/export/persistence coverage accompanies the change; manual visual/native GPU/platform acceptance and benchmarks remain pending.

## Animated Anchor Point

- Add local pixel Anchor X/Y to the Inspector, Transform tracks and Graph Editor, including Nulls, with keyframes, Linear/Bezier easing and the actual pivot marker. Add a playback-pausing dialog to reposition the pivot without moving the layer or descendants at the current frame, compensating static or animated Position in one Undo/Redo operation.
- Apply Anchor consistently through hierarchy-aware preview, playback, masks and export without invalidating source rasters. Write native `.motion` v11, read v1–v10 with zero Anchor, retain recovery wrapper v1, and reject nondefault Anchor in `.cscomp` v3 with layer-specific issues. Add geometry, UI, rendering, persistence and compatibility regression coverage; manual/platform acceptance and benchmarks remain pending.

## Layer parenting and Null controls

- Add Inspector Parent & Link selection and non-rendering Null control layers with position, rotation and uniform-scale animation. Preserve the current pose and existing curves when linking, changing or removing a parent, and detach children as one undoable operation when deleting a parent. Resolve hidden, inactive and offline ancestors consistently in preview/playback/export, without inheriting opacity, effects or masks.
- Persist parenting and compensation in native `.motion` v10, retain v1–v9 reading and recovery, and explicitly reject unsupported hierarchy data in `.cscomp` export. Nulls do not extend exports. Add EN/pt-BR labels and automated model, UI, rendering, export and compatibility coverage; manual acceptance remains pending.

## Animated effect parameters

- Add layer-local keyframe animation and Cubic Bezier Graph Editor easing for Gaussian Blur `radius_pixels` and Color Adjustment `brightness`, `contrast_percent`, and `saturation_percent`. Expose effect keyframe toggles in the Effects inspector, expandable `Effects` property tracks in the timeline, per-frame evaluation in CPU/GPU preview and video export, native `.motion` v9 persistence (reading v1–v9), and explicit `.cscomp` interchange rejection when effect keyframes are present.

## Shared rendering maintenance

- Preserve shared rendering compatibility while reducing experimental Vulkan
  conversion intermediates and adding known-memory allocation diagnostics.

## Shared graphics maintenance

- Reuse the private D3D11 NV12 converter with the standalone Vulkan input probe,
  preserving Motion native OpenGL color conversion and export contracts.

- Preserve the OpenGL consumer while adding optional command-batch and
  asynchronous-readback capabilities to the shared compositor interface.


## Gaussian Blur interchange

- Exchange editable Gaussian Blur and mixed ordered color/Blur stages through cscomp v3, preserving shared masks. Reuse the extracted shared CPU Blur implementation with the existing Motion worker pool and timings; native v8 is unchanged.

## Editable shape masks

- Add Inspector-edited shared Rectangle/Ellipse masks for content, effects and transformation, grayscale VIEW, composition-time linear/Bezier curves, history and CPU/GPU processing. Exchange editable masks through `.cscomp` v2 and persist them in native v8.

## Composition interchange

- Add editable `.cscomp` layer composition import/export with Video Editor, native v7 presentation metadata, preserved source clocks and text layouts, and worker-backed File commands.

## Changed

- Add a complete Brazilian Portuguese Motion Studio UI catalog. Bundle it for
  offline use and publish it through the translation manifest for next-launch
  updates delivered by the Hub.
- Add a General Settings language selector with independent System language, English, and pt-BR choices, applied on next launch. Load the selected Qt catalog from shared per-user storage before creating the Motion Studio interface; downloaded catalogs take precedence over bundled catalogs.

- Verify preview, GPU composition and export consumers against the shared composition mask-operation additions; Motion document behavior is unchanged.

## Improved

- Experimental hardware video encoders are no longer selected automatically.
  The export dialog now prefers a non-experimental encoder and leaves
  experimental hardware encoders available for explicit selection.
- Windows setup executables and installer wizards now display Motion Studio's
  application icon.

## Maintenance

- Use padded shared video-to-RGBA conversion with in-place row compaction to
  prevent buffer overruns while retaining the existing frame layout. Shared
  conversion and Motion preview/export regressions cover the consumer boundary.

- Use the revised shared update runtime with independent pending-app monitoring,
  schema-1 recovery, and per-app launch failure isolation. Add regressions for
  self-update shutdown and installer launch contention.

- Add Motion Studio producer/consumer coverage for Hub backup relocation across
  document versions 1–6, including linked Image Editor layer references.

## Shared rendering maintenance

- Preserve the existing OpenGL rendering entry points while the shared compositor
  gains a backend-neutral interface and optional Vulkan build support. This
  application continues to use OpenGL; Vulkan selection is Video Editor-only.
