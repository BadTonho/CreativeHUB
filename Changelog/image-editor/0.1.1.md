# Image Editor 0.1.1

Status: **Unreleased**. Changes accumulated since the published 0.1.0 baseline.

## Editable clipping masks

- Add Create/Release Clipping Mask to Layers with a customizable Ctrl+Alt+G
  shortcut (Command+Option+G on macOS), row marker/base tooltip, history and tabs.
- Compose sibling clipping chains from masked alpha, preserving base outlines
  and applying base opacity once across CPU/GPU preview, thumbnails and exports.
- Write `.cimg` v18, read v1-17 and recover v18 with the existing envelope.
  Preserve linked PNG publication and editable painting/selection targets.
- Allow isolated error-log directories in window tests so native recovery checks
  verify logged failures without depending on the user profile.
- Add English/pt-BR text, core/UI/cache/export/format/Hub/GPU regressions and a
  1080p workload. Native visual and macOS/Linux acceptance remain pending.


## Editable layer outline

- Add Outline controls below Layers with enable, thickness (1-1024 px), RGBA
  color, Inside/Outside placement, and removal. Preserve editable text/images;
  include masks, history, preview, thumbnails, export and linked PNG output.
- Introduce the `.cimg` v17 outline schema and recovery while reading versions 1-16;
  clipping masks advance the current writer to v18.
  Older editor binaries reject the new schema. Preserve application versions.
- Keep processed outline pixels within the existing cache budget and reuse them
  between unchanged frames. Correct retained-byte accounting when stale or
  deleted reference-raster cache entries are removed.
- Add English/pt-BR UI text and outline/model/UI/rendering/compatibility coverage.
  Native visual and macOS/Linux acceptance remains pending.


## Shared Drop Shadow processing maintenance

- Maintain compatibility with shared CPU effect and GPU image-operation extensions used by Motion Drop Shadow. Protect existing raster/mask/GPU rendering; Image controls and document formats are unchanged.

## Shared logical mask raster maintenance

- Retain existing raster/mask behavior, UI and persisted formats while shared coverage adds an optional logical receiver/raster window for Motion Bezier shapes. Protect the additive boundary with consumer regressions.

## Shared Track Matte compositor maintenance

- Preserve Image's existing raster/mask/image-operation behavior while shared
  CPU/OpenGL add a matte operation for Motion and Vulkan explicitly requests
  fallback. No Image feature UI or document fields are added; consumer gates
  protect the shared boundary.

## Shared blend-mode compositor maintenance

- Preserve Image rendering, image operations and native formats while the shared
  CPU/OpenGL compositor gains static layer modes for Motion; Vulkan refuses the
  new inputs explicitly. Consumer raster/mask/UI/export regressions protect
  existing defaults. No Image blend-mode UI or persistence is introduced; native
  GPU/platform acceptance remains separate from fallback coverage.

## Shared affine compositor maintenance

- Restore the standalone export-UI regression target's explicit translation dependency so it builds with the current window sources.

- Preserve Image rendering defaults while shared composition/Transform inputs gain an optional affine source-pixel override for Motion. CPU/precise OpenGL implement it and Vulkan explicitly requests fallback. Consumer raster/mask/export regressions protect the existing path; app versions and native acceptance status are unchanged.

## Shared rendering maintenance

- Preserve shared rendering compatibility while reducing experimental Vulkan
  conversion intermediates and adding known-memory allocation diagnostics.

## Shared graphics maintenance

- Retain Image OpenGL/raster behavior while adding the standalone Vulkan probe
  normalization operation to the shared optional shader build.

- Preserve the OpenGL consumer while adding optional command-batch and
  asynchronous-readback capabilities to the shared compositor interface.


## Changed

- Add a Settings > Language selector with independent System language, English, and pt-BR choices, applied on next launch. Load the selected Qt catalog from shared per-user storage before creating the Image Editor interface; downloaded catalogs take precedence over bundled catalogs.

- Add the complete pt-BR catalog for the visible Image Editor interface, bundle it for offline use, and publish it through the Hub translation manifest. The catalog covers menus, tools, panels, dialogs, accessibility labels, status messages, and validation errors while keeping logs and saved project data unchanged.

- Verify the existing GPU raster consumer against shared composition ApplyMask/MaskedBlend additions; Image document and raster-mask behavior are unchanged.

## Fixed

- Reject PNG/JPEG exports that would overwrite the document's original image
  or an imported image. The protection applies to full-document, selected-layer,
  and selected-group exports, including normalized paths, Windows path case
  differences, and existing paths that identify the same file.
- Preserve original file contents and document state when an export to a
  source image is rejected, while allowing export to a separate destination.

## Improved

- Windows setup executables and installer wizards now display the Image
  Editor's application icon.

## Maintenance

- Use the revised shared update runtime with independent pending-app monitoring,
  schema-1 recovery, and per-app launch failure isolation. Add regressions for
  self-update shutdown and installer launch contention.

- Add Image Editor producer/consumer coverage for Hub backup relocation across
  document versions 1–16, including source images and grouped raster imports.

- Add core and export-controller regressions for source-image preservation,
  including relative paths and filesystem aliases when the platform permits
  creating them.

## Validation

- The bundled pt-BR catalog and translation loading tests pass on Windows/Release. Native visual review in Portuguese and English, plus macOS/Linux startup checks, remain pending.

- On 2026-10-10, the core, raster, export UI, and application UI tests passed on
  Windows/Release; hard-link preservation also passed. Symbolic-link creation
  was unavailable under the local Windows privileges. Native visual checks and
  macOS/Linux validation remain pending.
- See the [manual validation checklist](../../docs/image-editor/validation/MANUAL_VALIDATION.md)
  for the export checks and remaining acceptance gates.

## Shared rendering maintenance

- Preserve the existing OpenGL rendering entry points while the shared compositor
  gains a backend-neutral interface and optional Vulkan build support. This
  application continues to use OpenGL; Vulkan selection is Video Editor-only.
