# Image Editor 0.1.1

Status: **Unreleased**. Changes accumulated since the published 0.1.0 baseline.

## Changed

- Verify the existing GPU raster consumer against shared composition ApplyMask/MaskedBlend additions; Image document and raster-mask behavior are unchanged.

## Fixed

- Reject PNG/JPEG exports that would overwrite the document's original image
  or an imported image. The protection applies to full-document, selected-layer,
  and selected-group exports, including normalized paths, Windows path case
  differences, and existing paths that identify the same file.
- Preserve original file contents and document state when an export to a
  source image is rejected, while allowing export to a separate destination.

## Improved

- Windows setup executables and installer wizards now display the Image
  Editor's application icon.

## Maintenance

- Use the revised shared update runtime with independent pending-app monitoring,
  schema-1 recovery, and per-app launch failure isolation. Add regressions for
  self-update shutdown and installer launch contention.

- Add Image Editor producer/consumer coverage for Hub backup relocation across
  document versions 1–16, including source images and grouped raster imports.

- Add core and export-controller regressions for source-image preservation,
  including relative paths and filesystem aliases when the platform permits
  creating them.

## Validation

- On 2026-10-10, the core, raster, export UI, and application UI tests passed on
  Windows/Release; hard-link preservation also passed. Symbolic-link creation
  was unavailable under the local Windows privileges. Native visual checks and
  macOS/Linux validation remain pending.
- See the [manual validation checklist](../../docs/image-editor/validation/MANUAL_VALIDATION.md)
  for the export checks and remaining acceptance gates.
